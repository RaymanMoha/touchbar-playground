# Artwork and brand references

## Gemini-chan

The unchanged Gemini-chan sprite atlas and manifest are from
[Wlaeg / Antigravity Pet](https://github.com/Wlaeg/antigravity-pet), specifically
the [Gemini-chan community pack](https://raw.githubusercontent.com/Wlaeg/antigravity-pet/main/community/packs/gemini-chan.zip).

Copyright (c) 2026 Antigravity Pet Contributors. The source repository's MIT
license is preserved in [Assets/antigravity-pet-LICENSE.txt](Assets/antigravity-pet-LICENSE.txt)
and bundled in the built application alongside the credits. No executable code
from that project is included. See [Assets/README.md](Assets/README.md).

Gemini-chan is a community character used here to represent Antigravity. This
project does not describe her as an official Google or Antigravity mascot.

## Codex and Claude

The native pixel drawings are adaptations based on Codex's bundled blue humanoid
companion and Claude Code's Clawd. Original brand characters and trademarks
belong to their respective owners. No original Codex sprite atlas or Claude
video is redistributed in this repository. This is an independent community
utility and does not imply endorsement by OpenAI, Anthropic or Google.

## Touch Bar API reference

[MTMR's private API declarations](https://github.com/Toxblh/MTMR/blob/master/MTMR/CBridge/TouchBarPrivateApi.h)
were consulted for AppKit method signatures. No MTMR implementation is bundled.
