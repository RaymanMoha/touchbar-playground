The user selected this Gemini-chan design as Antigravity's companion.

`gemini-chan.png` is the pack's original `spritesheet.png`, unchanged.
`gemini-chan.json` is the original `pet.json`, unchanged.
The atlas contains eight columns and eleven rows, with 192 × 208 pixel cells.
Native rendering chooses the existing animation frames, removes only transparent
side gutters at draw time and uses nearest-neighbour interpolation.

Gemini-chan is a community character chosen by the user, not a verified official
Google or Antigravity mascot. No code from the companion application is bundled.
